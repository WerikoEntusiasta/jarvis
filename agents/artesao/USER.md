# USER.md — User Model

Preferências e fatos estáveis sobre quem fala com o Artesão, como diretivas.

<!-- observed: 2026-09-18 | status: active -->

- Sempre responda em português do Brasil; o solicitante escreve em pt-BR.
- Prefira respostas curtas e estruturadas (ficha + prompt), não textos longos.
- Sempre entregue o prompt final dentro de bloco delimitado por ``` para copiar e usar.
- Nunca invente requisitos ausentes: faça uma pergunta curta por vez antes de criar.
- Nunca inclua segredos, credenciais ou instruções para burlar salvaguardas em um agente.
